# Verona Track 🏗️📱

**Verona Track** es una micro aplicación móvil offline diseñada específicamente para profesionales de la construcción, contratistas y trabajadores de oficios. Permite digitalizar y simplificar la gestión cotidiana de proyectos, obras y clientes desde la palma de la mano, sin depender de conexión a internet.

---

## 🚀 Características Principales

* **100% Offline:** Funciona sin necesidad de conexión a internet, garantizando disponibilidad total en obras alejadas o zonas sin señal.
* **Gestión de Obras y Clientes:** Administración centralizada de proyectos, datos de contacto y tareas pendientes.
* **Comunicación Directa:** Accesos rápidos integrados para realizar llamadas telefónicas o enviar mensajes de WhatsApp directamente desde el perfil de cada cliente.
* **Identidad Visual Corporativa:** Pantalla de carga inicial (*Splash Screen*) personalizada y una interfaz limpia.
* **Almacenamiento Local Robusto:** Utiliza bases de datos locales para mantener la privacidad y seguridad total de los datos en el dispositivo.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto está desarrollado bajo los estándares modernos de desarrollo para Android:
* **Jetpack Compose:** Para una interfaz gráfica moderna, fluida y reactiva.
* **Room (SQLite):** Para la persistencia de datos local de alto rendimiento.
* **Coil:** Para la carga eficiente y fluida de imágenes.
* **Kotlin:** Lenguaje de programación principal.
